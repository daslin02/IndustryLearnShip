# Практикум по C#

## 📋 Описание

Проект представляет собой интерактивный практикум, где каждое задание реализовано как отдельный класс с описанием, требованиями и решением. Пользователь может выбрать уровень, затем конкретное задание, прочитать его описание и запустить решение.

## 🚀 Инструкция по запуску

### Требования
- .NET 6.0 или выше
- Visual Studio 2022

### Шаги запуска

1. **Клонировать репозиторий**
   ```bash
   git clone https://github.com/daslin02/IndustryLearnShip
   cd IndustryLearnShip
   ```

2. **Открыть решение**
   - Visual Studio: открыть `IndustryLearnShip.sln`

3. **Запустить приложение**
   ```bash
   dotnet run
   ```

4. **Навигация по меню**
   - Введите номер уровня (1-3) для выбора группы заданий
   - Введите номер задания для его запуска
   - Введите `q` для выхода
